# MNIST Project

> **Lưu ý:** Dự án này đang trong giai đoạn phát triển (Work in Progress). Tài liệu và mã nguồn có thể thay đổi mà không cần báo trước.

## 📝 Mô tả
Kho lưu trữ này chứa các mã nguồn và quy trình xử lý cho bộ dữ liệu **MNIST** (Modified National Institute of Standards and Technology). Mục tiêu là xây dựng pipeline để phân loại chữ số viết tay.

Dự án hiện đang tập trung vào việc thiết lập cấu trúc cơ bản và chuẩn bị dữ liệu.
